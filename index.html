Hermes Google Drive Integration

This is a private, single-user integration that allows the owner's Hermes Agent installation to work with the owner's Google Drive, Google Docs and Google Sheets after explicit OAuth authorization.

The application is not offered as a public service and does not provide access to third parties.

Інтеграція Hermes із Google Drive

Приватна однокористувацька інтеграція для роботи власника з Google Drive, Google Docs і Google Sheets після явного підтвердження OAuth-доступу.
